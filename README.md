# JS-TicTacToe
A browser game of tic-tac-toe for two players. It uses HTML, CSS, and JavaScript.

## Features

- Two players, with names that you enter at the start
- Player 1 uses `O`. Player 2 uses `X`.
- The score for each player shows on the page
- A preview of the mark shows when you move the pointer over an empty cell
- A dialog shows the result at the end of each round
- A reset button starts a new game with new players
